분류 모델 평가 기준

| 항목 | 의미와 사용 방법 |
| --- | --- |
| Macro F1 | 주제별 F1을 같은 비중으로 평균. 모델 선정의 우선 지표 |
| Accuracy | 전체 질문 중 상담 주제를 맞힌 비율 |
| 주제별 Precision·Recall·F1 | 특정 주제의 오분류와 누락을 분석 |
| 업무 외 탐지·정상 문의 오차단 | 차단 기능과 정상 고객 문의 손실을 함께 확인 |

**발표 노트**

> 분류 모델은 전체 정답 비율인 Accuracy와 주제별 F1을 같은 비중으로 평균한 Macro F1을 함께 봅니다. 데이터가 불균형하므로 검증 Macro F1을 우선했습니다. BERT 체크포인트도 검증 Macro F1로 선택한 뒤 Test를 확인했습니다. 처음 설계한 속도와 자원 비교는 이번 최종 분류 실험에서 측정하지 않았으므로 선정 근거에 넣지 않았습니다.

생성 모델 평가 기준

선정 우선순위

사용 가능 비율, 외부 전송 여부, 정확성, 생성 시간, 비용 순으로 판단

| 판정 | 조건 |
| --- | --- |

| 채점 항목 | 확인 내용 | 척도 |
| --- | --- | --- |
| 정확성 | 확인 가능한 사실과 일치하는가 | 0–2점 |

**발표 노트**

> 비교 이력에는 베이스라인과 BERT 실험일, 실험이가 있습니다. BERT 실험일은 은행 주제만 다룬 이전 실험입니다. 이번 최종 선정 표는 은행과 업무 외를 합친 동일한 클래스 구성의 베이스라인과 BERT를 비교합니다. 따라서 이전 은행 전용 점수를 이번 전체 점수와 직접 비교하지 않았습니다. BERT는 전체 파인튜닝했으며 최적 체크포인트는 checkpoint-7473입니다.
